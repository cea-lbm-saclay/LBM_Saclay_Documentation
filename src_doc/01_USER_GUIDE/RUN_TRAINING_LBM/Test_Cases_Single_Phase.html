Run “Single phase test cases”

Poiseuille flow

For training session: local computer

Go to one test case of run_training_lbm, e.g. TestCase01_Poiseuille_Water:

$ cd ~/run_training_lbm/TestCase01_Poiseuille_Water

Run LBM_saclay with the input file name.ini

$ ~/LBM_Saclay_Rech-Dev/build_omp/build_NSAC_Comp/src/LBM_saclay TestCase01_Poiseuille_Water.ini

Once the simulation is complete (78.891 seconds on CPU of is154726 for 250.000 time-steps), follow the instructions below

In paraview12

For training session: post-processing with paraview

Two methods are possible to extract a profile from vti files with paraview. Both will save \(u_x(y)\) values at the final time of simulation in a new file called Poiseuille_Water.csv.

Open paraview12 and follow the instructions below to create the profile Poiseuille_Water.csv:

  1. Open TestCase01_Poiseuille_Water_FINAL.vti file and Apply

  2. Ctrl space + Cell Data to Point Data and Apply

  3. Ctrl space + Plot Over Line

  4. Select Sample At Segment Centers Clic on Y axis and Apply –> new graph with profile

  5. File –> Save Data, file name: Poiseuille_Water.csv and OK

The five previous commands are saved inside a python script Extract-Profile_Poiseuille_PV5-12-1.pvpy. You can use it with pvpython:

$ /tmp_formation/LBM_Saclay/ParaView/ParaView-5.12.1-MPI-Linux-Python3.10-x86_64/bin/pvpython  Extract-Profile_Poiseuille_PV5-12-1.pvpy

The script will generate automatically the output file Poiseuille_Water.csv

Run python script

For training session: python script

Next in your terminal

$ python Post-Pro_Poiseuille_CompareAnaly.py

If the computation has run on GPU use

$ python Post-Pro_Poiseuille_CompareAnaly_GPU.py

In input file TestCase01_Poiseuille_Water.ini test successively nStepmax=250000 and nStepmax=500000. The python script must plot Fig. 8.

For training session: if problem with plot

Check in Poiseuille_Water.csv file that the column numbers of "vx" and "Points:1" match with numbers set in Post-Pro_Poiseuille_Water_CompareAnaly.py file:

if row[0]!= 'laplaphi':
      x_star = np.append(x_star, float(row[32]))
      u_star = np.append(u_star, float(row[10]))

Lid driven cavity flow

For LBM training session: example on Orcus

Run one of the three .ini file, e.g. for Re=1000:

$ sbatch /tmpformation/LBM_Saclay/JOB_H100_GPU.slurm TestCase01_Lid_driven_cavity_flow_Re1000.ini

On gpuq_h100 of Orcus, the simulation ran 55.300 seconds to achieve 200.001 time-steps..

Once the simulation is complete, in paraview12

For training session: commands in paraview

  1. Open lid_driven_cavity_flow_1000_FINAL.vti file and Apply

  2. Ctrl space + Cell Data to Point Data and Apply

  3. Ctrl space + Plot Over Line

  4. Select Sample At Segment Centers Clic on Y axis and Apply –> new graph with profile

  5. File –> Save Data, file name: profil_lid_driven_cavity_BGK_1000_Ux.csv and OK

Next in your terminal

For training session: python script

$ python Post-Pro_Lid_Driven_Cavity_Flow_Profile_Ux_y_Re1000.py
